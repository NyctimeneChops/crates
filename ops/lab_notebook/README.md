# Lab Notebook

A running record of what was attempted on this project, what happened, and what was
learned. It is a decision-and-experiment log, not documentation of the finished
system.

## Rules

- **Append-only.** Never edit or delete a past entry. If something in a past entry
  turns out to be wrong, do not change it — write a new entry that corrects it.
- **Git history is the immutability guarantee.** The value of this notebook depends
  on entries not being rewritten after the fact; the commit history is what proves
  they weren't.
- **Sequential entries:** `CR-001`, `CR-002`, `CR-003`, ...
- **`CR-` prefix** is deliberate, to avoid collision with a separate project that
  uses the `LN-` prefix.
- **Status values:** `in progress` | `complete` | `abandoned`.
- **Abandoned entries matter as much as completed ones.** An approach that did not
  work is a result. Record what was tried and why it was dropped, so it is not
  silently attempted again.

## Template

```
# CR-00N: <short title>
Date:
Status: in progress | complete | abandoned

## What I set out to do
## What happened
## What I learned
## What's next
```
